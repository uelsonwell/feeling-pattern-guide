# Emotional Compass

Quero criar uma Matriz de comportamento e padrões emocionais. Nessa Matriz temos: Perguntas e respostas com multiplas escolhas. Temos o peso em cada uma dessas respostas e precisamos dar uma devolutiva para os clientes ao final do questionário. Vc consegue me auxiliar nessa tarefa?

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://feeling-pattern-guide.lovable.app
